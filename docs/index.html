02 · KHỞI TẠO CLIENT

Kết nối sandbox hoặc production.

Lấy partnerCode, accessKey và secretKey từ MoMo Developer Portal. Sandbox là lựa chọn an toàn để phát triển và kiểm thử.

MoMo Developer Portal ↗ 
import {
  MomoClient,
  MOMO_SANDBOX_URL,
  MOMO_PRODUCTION_URL
} from "momo-payment";

const momo = new MomoClient({
  partnerCode: process.env.MOMO_PARTNER_CODE,
  accessKey: process.env.MOMO_ACCESS_KEY,
  secretKey: process.env.MOMO_SECRET_KEY,
  endpoint: MOMO_SANDBOX_URL,
  timeoutMs: 30_000
});

// Production: endpoint: MOMO_PRODUCTION_URL
Timeout tối thiểu là 30 giây. Mọi request tới MoMo yêu cầu timeoutMs >= 30_000. Giá trị nhỏ hơn sẽ bị từ chối với mã INVALID_ARGUMENT.

03 · PAYMENT API

Một client, toàn bộ vòng đời giao dịch.

Tạo payment URL

Gọi createPayment() để tạo giao dịch và redirect người dùng tới payUrl.

const payment = await momo.createPayment({
  orderId: "ORDER_123",
  amount: 100000,
  orderInfo: "Thanh toan don hang",
  redirectUrl: "https://example.com/return",
  ipnUrl: "https://example.com/ipn"
});

console.log(payment.payUrl);

Query giao dịch

Tra cứu trạng thái mới nhất theo orderId và một requestId duy nhất.

const status = await momo.queryTransaction({
  requestId: "QUERY_ORDER_123",
  orderId: "ORDER_123",
  lang: "vi"
});

console.log(status.resultCode, status.message);

Confirm hoặc cancel

Với giao dịch authorize, dùng capture để nhận tiền hoặc cancel để hủy.

await momo.confirmPayment({
  requestId: "CONFIRM_ORDER_123",
  orderId: "ORDER_123",
  requestType: "capture",
  amount: 100000,
  lang: "vi"
});

Refund và query refund

Hoàn tiền toàn phần hoặc một phần cho giao dịch đã thanh toán thành công.

const refund = await momo.refundPayment({
  requestId: "REFUND_ORDER_123",
  orderId: "REFUND_123",
  amount: 50000,
  transId: status.transId,
  description: "Khach hang yeu cau hoan tien"
});

await momo.queryRefund({
  requestId: "REFUND_QUERY_123",
  orderId: refund.orderId
});

queryTransaction()POST /v2/gateway/api/query
confirmPayment()POST /v2/gateway/api/confirm
refundPayment()POST /v2/gateway/api/refund
queryRefund()POST /v2/gateway/api/refund/query

04 · IPN CALLBACK

Xác thực trước khi ghi nhận thanh toán.

MoMo gọi ipnUrl sau khi trạng thái giao dịch thay đổi. Luôn xác thực chữ ký, đối chiếu orderId, amount, resultCode và xử lý idempotency trước khi cập nhật database.

Chuỗi IPN được ký bằng HMAC-SHA256 với accessKey ở đầu chuỗi và so sánh bằng timing-safe comparison.

import express from "express";

const app = express();
app.use(express.json());

app.post("/payments/momo/ipn", async (req, res) => {
  if (!momo.verifySignature(req.body)) {
    return res.status(400).json({
      success: false,
      message: "Invalid MoMo signature"
    });
  }

  // Đối chiếu order/amount và bỏ qua callback đã xử lý.
  if (req.body.resultCode === 0) {
    // Update transaction after idempotency checks.
  }

  return res.json({ success: true });
});

05 · ERROR HANDLING

Lỗi rõ ràng, dễ xử lý.

MomoApiError dành cho lỗi từ MoMo hoặc HTTP failure. MomoError dành cho lỗi input, timeout, network và response không hợp lệ.

import {
  MomoApiError,
  MomoError
} from "momo-payment";

try {
  await momo.createPayment(/* ... */);
} catch (error) {
  if (error instanceof MomoApiError) {
    console.error(error.response.resultCode);
  } else if (error instanceof MomoError) {
    console.error(error.code, error.message);
  }
}
