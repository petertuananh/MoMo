02 · TẠO PAYMENT

Tạo payment URL.

MoMo trả về payUrl. Bạn có thể redirect người dùng hoặc trả URL cho frontend.

MoMo Developer Portal ↗ 
import { MomoClient,
  MOMO_SANDBOX_URL } from "momo-payment";

const momo = new MomoClient({
  partnerCode: process.env.MOMO_PARTNER_CODE,
  accessKey: process.env.MOMO_ACCESS_KEY,
  secretKey: process.env.MOMO_SECRET_KEY,
  endpoint: MOMO_SANDBOX_URL
});

const payment = await momo.createPayment({
  orderId: "ORDER_123",
  amount: 100000,
  orderInfo: "Thanh toan don hang",
  redirectUrl: "https://example.com/return",
  ipnUrl: "https://example.com/ipn"
});

console.log(payment.payUrl);

03 · XÁC THỰC IPN

Không bỏ sót giao dịch.

Luôn xác thực signature, orderId, amount và kiểm tra idempotency trước khi cập nhật database.

app.post("/payments/momo/ipn", (req, res) => {
  if (!momo.verifySignature(req.body)) {
    return res.status(400).json({
      success: false
    });
  }

  // Update transaction after idempotency checks.
  return res.json({ success: true });
});
